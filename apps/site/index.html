OpenVI

An unofficial, open-source explorer and data-mining toolkit for GTA VI files, in the spirit of OpenIV.

Browse the folders and RPF9 archives of your own install, look inside them in 3D, and catalog what the game holds: vehicles, characters, animations, textures.

Download Source code
  • Windows · macOS · Linux
  • GPL-3.0, free software
  • Reads your files, never changes them

OpenVI reads the unencrypted data of the files you own, entirely on your machine. It decrypts nothing, ships no game files and uploads nothing. The archives' table of contents is encrypted, so inside an archive resources are found by scanning its data and grouped by type, named where the data carries a name.

What it does

A dense desktop explorer first, with sections for the game's data beside it. A click previews in the right pane, a double-click opens.

Explorer

Folder tree, details list grouped by type, path bar, filter, history and keyboard navigation, in the OpenIV tradition.

RPF9 archives

Open an archive like a folder: its resources by type (models, textures, text), with the names they carry. The first scan is cached.

Search

A local SQLite index of every archive with full-text search: any part of a name finds it, and a result opens its archive on the resource.

3D viewer

Drawables, fragments and dictionaries with their textures. Lit, Unlit, Clay, Normals and Wire modes, a materials panel and an animation player.

Vehicles

The vehicle catalog: name, model, make, handling, mass, top speed, gears. Sortable, exported as CSV or JSON, and each car in 3D in any of its configurations.

Characters

Every character and animal that can be assembled from its parts, shown in 3D. Wear one part per slot: head, hair, top, bottom, feet.

Animations

Clip dictionaries and their clips, played on a character or on its skeleton alone, with a time line and speed from ×0.25 to ×2.

Textures and documents

Textures decoded to PNG; text, XML and JSON in a code editor with highlighting and formatting.

Exports

Models and vehicles as glTF (GLB and textures), textures as PNG, raw resources, catalogs as CSV and JSON. On your machine only.

Get started

Download

Installers for Windows, macOS (Apple silicon and Intel) and Linux are published on GitHub Releases. They are not signed yet: Windows SmartScreen and macOS Gatekeeper will ask you to confirm the first launch.

Open the folder of your GTA VI install, then browse it, or pick a section: Vehicles, Characters, Animations.

GitHub Releases

Build from source

Node.js 26, pnpm 12, Rust 1.90 and the Tauri 2 prerequisites. 

git clone https://github.com/TheoBIET/OpenVI.git
cd OpenVI
pnpm install
pnpm dev

Credits

OpenVI stands on the research of the GTA VI reverse-engineering community, in particular SixNG, whose format decoders are OpenVI's core, and awesome-gta6-reverse-engineering. The explorer's layout pays tribute to OpenIV.
